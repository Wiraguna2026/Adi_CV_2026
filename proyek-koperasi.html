Website Pengelolaan Koperasi Merah Putih

Website untuk pencatatan keuangan koperasi agar pengelolaannya lebih tertib dan mudah dipantau.

HTML CSS Bootstrap

Tentang proyek

Website ini dibuat untuk membantu pengurus koperasi mencatat dan mengelola keuangan koperasi. Pencatatan yang sebelumnya manual dipusatkan dalam satu sistem sehingga data lebih rapi, mudah dicari, dan mudah dilaporkan.

Peran saya

Merancang alur sistem, membuat desain antarmuka, dan membangun halaman website.

Fitur utama

  • Pencatatan keuangan

    Mencatat pemasukan dan pengeluaran koperasi secara tertib.

  • Pengelolaan data

    Data keuangan tersimpan terpusat sehingga mudah dicari dan diperiksa kembali.

  • Tampilan responsif

    Halaman dapat dibuka dengan nyaman dari komputer maupun ponsel.
