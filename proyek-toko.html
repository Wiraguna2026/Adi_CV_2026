Toko Ikan Hias Online Sederhana

Website toko ikan hias dengan katalog pemilihan ikan dan keranjang belanja.

PHP MySQL HTML CSS Bootstrap

Tentang proyek

Website ini dibuat agar pembeli dapat melihat dan memilih ikan hias secara online. Pembeli menelusuri katalog, memasukkan ikan yang diinginkan ke keranjang, lalu melanjutkan pemesanan. Data produk dan pesanan disimpan di database MySQL.

Peran saya

Merancang tampilan website, menyusun struktur database, dan membuat program menggunakan PHP.

Fitur utama

  • Katalog ikan hias

    Menampilkan daftar ikan hias lengkap dengan gambar, nama, dan harga agar pembeli mudah memilih.

  • Keranjang belanja

    Pembeli dapat menambah, mengurangi, dan menghapus ikan di keranjang sebelum memesan.

  • Penyimpanan data

    Data produk dan pesanan tersimpan rapi di database MySQL.
